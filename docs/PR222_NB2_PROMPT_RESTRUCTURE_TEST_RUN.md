## Gotchas

- **Codegen owns `index.ts`.** New api-zod modules MUST be registered in
  `patch-generated.mjs`'s allowlist, not just added to `index.ts` — a bare
  `index.ts` edit is silently reverted on the next codegen. (This bit us; the
  fix is in this PR.)
- **`api-zod` resolves to source** (`package.json` exports `./src/index.ts`), so
  a stale `dist` is not the issue — the source `index.ts` export list is.
